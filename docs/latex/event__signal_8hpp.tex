\doxysubsection{Detailed Description}
Lightweight thread-\/based signaling primitive for sync waiting. 

{\ttfamily event\+\_\+signal} is used by helper utilities such as {\ttfamily sync\+\_\+wait()} to bridge coroutine completion to blocking caller code.
