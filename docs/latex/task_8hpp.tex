\doxysubsection{Detailed Description}
Core coroutine task type used across Web\+Craft async APIs. 

{\ttfamily \doxylink{classwebcraft_1_1async_1_1task}{webcraft\+::async\+::task}\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}} represents an awaitable operation that produces a value of type {\ttfamily T} (or {\ttfamily void}). Most high-\/level async APIs in this project return this type.
