\doxysubsection{Detailed Description}
Coroutine return type for detached, non-\/owning asynchronous work. 

Use {\ttfamily fire\+\_\+and\+\_\+forget()} to run a {\ttfamily task\texorpdfstring{$<$}{<}void\texorpdfstring{$>$}{>}} without awaiting its result, typically for orchestration paths where completion is observed elsewhere.
