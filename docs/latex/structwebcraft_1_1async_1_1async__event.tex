\doxysubsection{Detailed Description}
One-\/shot awaitable event for coroutine coordination. 

Coroutines can suspend on this object and are resumed when {\ttfamily \doxylink{structwebcraft_1_1async_1_1async__event_a49de077f7eace2cd7a8ed81b257a7379}{set()}} is called. Once set, subsequent awaits complete immediately.
